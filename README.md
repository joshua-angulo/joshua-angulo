## What I've built

I built all of it: the Next.js and React web app, the Node.js API, 20 background workers on Redis, Stripe and Mercado Pago payments, and 1,066 automated tests. Meta approved it as a WhatsApp Tech Provider.

**A real-time data and ML platform** (2026 to present). A recorder on AWS captures live crypto-market data (38.8M events so far), machine-learning models are trained on it, and a program written in Rust runs those models in real time.

**City of Lynwood, California** (2023 to 2024, contract). I worked with city staff on a chat and phone assistant that answers residents' questions.
